# Como contribuir

Obrigado pelo interesse em contribuir com este repositório!

1. Crie uma branch a partir da `main` (ex.: `feat/minha-mudanca`).
2. Faça commits pequenos com mensagens claras (ex.: `feat:`, `fix:`, `docs:`).
3. Abra um Pull Request descrevendo o que foi alterado e por quê.
4. Aguarde a revisão antes do merge na `main`.

## Boas práticas

- Mantenha cada Pull Request focado em uma única mudança.
- Atualize a documentação sempre que alterar algum comportamento.
- Seja respeitoso e construtivo nas revisões.
